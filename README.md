# cat6-rj45-cabling-lab
Hands-on Cat6 UTP Ethernet cabling lab: stripped and prepared conductors, terminated an RJ45 connector, crimped the cable, and tested continuity with a network cable tester. Demonstrates Layer 1 troubleshooting, Ethernet cabling, RJ45 termination, and CompTIA A+/Network+ skills.
### 🔌 Cat6 RJ45 Ethernet Cable Termination
